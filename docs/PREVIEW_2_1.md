Open **Coach** for an untimed game against a local bot. Pick a side and a strength, then play. The practice opponent calculates its reply to the position on the board. Bot Elo numbers are estimates.

For each move, a separate Stockfish search checks the position before and after it. A badge on the piece shows the grade, and the notebook shows the search depths and evaluation from White’s perspective. This includes opening moves. When Stockfish cannot verify a move at sufficient depth, it stays unrated. Use the arrows to revisit a move or **Study position** to try a continuation from the engine’s lines.

Choose **Windows-Setup.exe** for the installed app, **Windows-x64.exe** for portable play, or **web.zip** to host the web app. Windows executables are unsigned. The release includes the source archive and SHA-256 checksums.

This preview includes Windows and web. The Android release build passed its native tests and could not complete signing. Existing Android installations require an APK signed with Knightfall’s original application signing key. Stable automatic updates exclude this preview.

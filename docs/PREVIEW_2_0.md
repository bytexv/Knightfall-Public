Knightfall 2.0.1 adds automatic best-move feedback after likely mistakes in coached bot games.

Knightfall 2.0 introduces a local position coach, editable premove queues, Modern and Legacy navigation, new board palettes, a first-launch update log, and a result card over the final position. The bot picker now compares local ratings and head-to-head results.

Choose **Windows-Setup.exe** for the installed app, **Windows-x64.exe** for portable play, or **web.zip** to host the web app. Windows executables are unsigned. The source archive, release notes and SHA-256 checksums are included.

This preview includes the tested Windows and web builds. A compatible Android APK requires the original signing key. Android users can keep their current app and saved games. Stable automatic updates exclude this preview.
